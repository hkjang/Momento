Momento 관리자 가이드 (Admin Guide)

버전: v0.1.0 대상: 시스템 관리자, Security/DevOps 엔지니어 분류: 시스템 관리 매뉴얼

1. 초기 환경 설정 & 부트스트랩

Momento 프로세스는 오직 다음 3개의 표준 환경변수만 요구합니다.

MOMENTO_POSTGRES_DSN=postgres://momento:password@localhost:5432/momento?sslmode=disable
MOMENTO_BOOTSTRAP_ADMIN=admin@corporate.internal
MOMENTO_BOOTSTRAP_ADMIN_PASSWORD=SuperSecretPassword123!
설정 원칙: 그 밖의 모든 공개 URL, Keycloak 클라이언트 정보, 개인정보 차단 규칙, CIDR 대역은 DB에 보관되는 동적 관리자 설정입니다.

2. Keycloak OIDC SSO 및 RBAC 연동

PKCE(S256)를 적용한 표준 Keycloak OIDC 연동 및 사용자 역할(RBAC) 매핑 가이드:

  • Momento_Admin: 전체 사이트 설정, PII 필터, API 키 및 감사 로그 접근 권한
  • Momento_Analyst: 쿼리 빌더, 퍼널 및 경로 분석 조회 권한
  • Momento_Viewer: 개요 및 실시간 대시보드 전용 조회 권한

3. 개인정보(PII) 자동 차단 & 보안 관리

수집기(Collector)에 유입되는 이벤트의 속성 및 user_id에서 이메일, 주민번호, 전화번호 패턴을 자동 마스킹 및 차단합니다.

4. CIDR 수집망 대역 이름 맵핑

사내 C클래스 및 CIDR IP 대역을 특정 오피스, R&D 센터, VPN 망 이름으로 맵핑하여 사내 네트워크별 사용 현황을 분석할 수 있습니다.

5. 감사 로그 (Audit Trail) 운영

사이트 생성, PII 규칙 변경, API 키 생성 및 사용자 권한 변경 등 모든 관리자 행위는 수정 불가능한 감사 로그(Audit Logs)로 영구 기록됩니다.
