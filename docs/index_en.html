Own Your Raw Event Data
Without 3rd-Party Leaks

Understand who, in which department, uses which feature at raw-event scale

Momento is a self-hosted, on-premise event analytics engine that collects and stores behavioral data from internal web and mobile applications. Enjoy complete data sovereignty, Keycloak OIDC integration, and native Analytics MCP for AI agent interaction.

Core Features

Purpose-built for enterprise security, internal tool adoption, and custom analytics

📡

Rich JS SDK & Offline Queue

Track PageViews, SPA routing, clicks, scrolls, form inputs, downloads, outbound links, errors, heartbeats, with automatic Beacon and offline retry queues.

🔍

Raw Event Query Builder

Store complete raw events rather than aggregated metrics. Query custom properties, filter by department/org, and analyze 2-10 step Funnels and Path flows.

🌐

CIDR Subnet Mapping

Map internal C-class and CIDR IP subnets to headquarters, R&D centers, or branch office names to measure physical network usage distribution.

🔐

PII Masking & Enterprise Security

Automatically redact sensitive PII patterns (emails, SSNs, phone numbers). Supports Keycloak OIDC (PKCE), RBAC, API key rotation, and audit logs.

🤖

Analytics MCP Integration

Streamable HTTP MCP JSON-RPC endpoint allows AI assistants like Claude Desktop and Cursor to query analytics metrics natively in conversation.

📦

Air-Gapped Deployment

Deploy in isolated corporate networks using a single non-root Docker container and offline tar.gz release archives with zero external dependencies.

Enterprise Security & Governance

Comprehensive protection designed for strict compliance standards

🔑

Keycloak OIDC SSO

Standard OIDC login with PKCE (S256). Maps Keycloak groups and roles directly into Momento RBAC permissions.

🔒

API Key Rotation

Issue hashed API keys with zero-downtime grace period rotation. Raw keys are shown once upon creation.

🛡️

PII Redaction Rules

Automatic detection and masking of sensitive identifiers. Customize blocking rules dynamically via the admin console.

📝

Audit Trail Logs

Structured audit logging for site creation, key generation, PII rule changes, and user permission updates.

Track user identity and custom events with just a few lines of code.

Flexible Deployment

Choose the deployment model that best fits your environment

🐳 Docker Compose

Run PostgreSQL and the Momento single container service together. The fastest way for local evaluation.

cp .env.example .env
# Configure admin credentials in .env
docker compose up --build

# Web Admin: http://localhost:8080

📦 Offline Archive (.tar.gz)

Docker image bundle for air-gapped corporate networks without internet access.

# Load the release archive
gzip -dc momento-v0.1.0.tar.gz | docker load

# Run in air-gapped environment
docker run -d -p 8080:8080 \
  -e MOMENTO_POSTGRES_DSN='...' \
  momento:v0.1.0

Frequently Asked Questions

Momento is an on-premise event analytics platform designed to capture, own, and analyze raw user interaction events across internal web tools and mobile apps without relying on third-party cloud services.

Internal tool usage contains confidential organizational data, department names, and employee activity details. Momento keeps 100% of data inside your infrastructure and works seamlessly in air-gapped networks.

A single PostgreSQL 14+ database is all you need. Momento does not require Redis or complex external queue clusters for high-performance event ingestion.

Momento exposes a /mcp JSON-RPC endpoint. AI tools like Claude Desktop or Cursor can connect directly using an API key to ask questions like "Which department used feature X most this week?"
