## 1. 개요 및 사용자 분류 체계

Momento 플랫폼은 엔터프라이즈 사내 조직의 5대 주요 직군(CISO/보안팀, C-Level 경영진, 서비스 PO/기획자, 데이터 분석가, 개발 팀)이 요구하는 보안 컴플라이언스 및 분석 가치를 완벽히 만족하도록 설계되었습니다.

```
========================================================================================
                       [Momento 5대 핵심 사용자 직군 및 가치]
========================================================================================
 [1. CISO / 정보보안 팀]   ➔ 100% 온프레미스 & PII 자동 마스킹으로 외부 유출 위험 0%
 [2. C-Level 경영진]        ➔ 사내 IT 인프라 및 애널리틱스 TCO 75% 절감 및 데이터 주권
 [3. 서비스 PO / 기획자]    ➔ 사내 부서별/망대역별 기능 이용률, 퍼널 및 이탈 경로 시각화
 [4. 데이터 분석가 / BI]    ➔ Raw Event 쿼리 빌더 및 Raw CSV/NDJSON 데이터 웨어하우스 연동
 [5. SRE / Dev통합 팀]      ➔ 비동기 JS SDK, 오프라인 큐 및 Analytics MCP 기반 AI 자동화
========================================================================================
```

## 2. 페르소나별 상세 시나리오 분석

### 2.1 CISO & 정보보안 팀 (Information Security)
- **Pain Point**: 기존 GA 등 외부 SaaS 사용 시 사내 임직원의 접속 이력, 부서 정보, 업무 패턴 등 기밀 데이터가 외부 구글/SaaS 서버로 전송되어 보안 컴플라이언스 위반 우려.
- **Momento Solution**:
  - 외부 인터넷 통신이 차단된 폐쇄망(Air-Gapped) 인프라에 단일 Docker 컨테이너 및 오프라인 `.tar.gz` 번들 형태로 완벽 배치.
  - 수집기(Collector) 레벨에서 이메일, 주민번호, 전화번호 패턴을 정규식으로 자동 마스킹 처리.
  - Keycloak OIDC SSO(PKCE) 및 RBAC 역롴 권한 분리, 무결성 감사 로그(Audit Trail) 영구 보관.

### 2.2 서비스 기획자 & Product Owner (PO)
- **Pain Point**: 신규 사내 포털, 전자결재, ERP의 특정 기능이 어떤 부서에서 얼마나 활발히 쓰이는지 가시적인 통계 부족.
- **Momento Solution**:
  - 사내 부서명, 직급, C클래스/CIDR 서브넷 망대역을 자동 매핑하여 부서별/오피스별 기능 활용률을 분석.
  - 2~10단계 목표 전환 퍼널과 사용자 이동 경로(Path) 시각화로 유저 UX 이탈 지점 도출.

### 2.3 프론트엔드 / 백엔드 개발자 & SRE
- **Pain Point**: 이벤트 수집 로직 구현 부담 및 네트워크 유실 시 행동 데이터 분실.
- **Momento Solution**:
  - 단 한 줄의 스크립트 비동기 태그 삽입으로 PageView, Click, Error 자동 트래킹.
  - Beacon API 및 IndexedDB 오프라인 큐로 네트워크 복구 시 자동 재전송.
  - Streamable HTTP Analytics MCP 지원으로 Cursor, Claude 등 AI 개발 환경에서 대화형 지표 질의 가능.

## 3. 결론

Momento 플랫폼은 보안팀의 엄격한 규정 준수 요구사항부터 개발자, 기획자, 데이터 분석가의 생산성 극대화까지 사내 모든 구성원이 100% 안심하고 활용할 수 있는 차세대 데이터 인프라입니다.
