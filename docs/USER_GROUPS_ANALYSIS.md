# Momento 타겟 사용자군 분석 보고서 (Target User Groups Analysis)

- **작성일**: 2026년 8월 8일  
- **대상**: 경영진, 인사/보안 담당자, IT 서비스 기획자, 개발 팀  
- **문서 목적**: 사내 직군 및 역할별 Momento 페르소나 정의, 활용 시나리오 및 페인 포인트 해결 방안 제시  

---

## 1. 개요 및 사용자 분류

Momento는 엔터프라이즈 사내 환경에서 다양한 부서와 직군이 데이터 보안을 준수하면서 맞춤형 이점과 가치를 누릴 수 있도록 설계되었습니다.

```
+-----------------------------------------------------------------------------------+
|                        Momento 핵심 타겟 페르소나 (Personas)                      |
+-----------------------------------------------------------------------------------+
| [1. CISO / 정보보안 팀]   ➔ 100% 온프레미스 & PII 자동 마스킹으로 외부 유출 제로  |
| [2. 서비스 기획 / PO]     ➔ 사내 기능별 사용율, 퍼널 및 부서별 이용 현황 측정     |
| [3. 데이터 분석가]        ➔ Raw Event 기반 쿼리 빌더 및 BI 도구(CSV/NDJSON) 연동  |
| [4. Frontend/Backend 개발자] ➔ 비동기 JS SDK 및 Analytics MCP 기반 AI 자동화      |
| [5. 경영진 (C-Level)]     ➔ 사내 IT 시스템 및 인프라 TCO 75% 절감 및 데이터 주권   |
+-----------------------------------------------------------------------------------+
```

---

## 2. 사용자 페르소나별 상세 시나리오

### 2.1 CISO & 정보보안 팀 (Information Security)
- **Pain Point**: 기존 GA 등 외부 SaaS 사용 시 사내 임직원 행동 패턴 및 서비스 비밀 데이터가 외부 구글/SaaS 서버로 전송되어 보안 컴플라이언스 위반 위험 발생.
- **Momento Solution**: 
  - 100% 온프레미스 및 에어갭(Air-Gapped) 설치로 외부 인터넷 통신 차단.
  - 이메일, 주민번호 등 민감 데이터 수집기 단위 자동 마스킹 및 Keycloak OIDC SSO 통합.

### 2.2 서비스 기획자 & Product Owner (PO)
- **Pain Point**: 새로 오픈한 사내 전자결재/ERP/인트라넷 기능이 어느 부서에서 실제로 많이 쓰이는지 객관적인 수치로 파악하기 어려움.
- **Momento Solution**:
  - 사내 부서 및 CIDR 망 대역별 기능 이용 현황 시각화.
  - 2~10단계 퍼널 및 유저 이동 경로(Path) 분석으로 서비스 개선점 도출.

### 2.3 프론트엔드 / 백엔드 개발자
- **Pain Point**: 웹/앱 이벤트 수집 코드 작성이 복잡하고 네트워크 유실 시 데이터가 유실됨.
- **Momento Solution**:
  - 비동기 JS SDK의 Beacon 및 오프라인 큐 재전송 지원.
  - Analytics MCP를 통한 AI 에이전트(Claude, Cursor) 자동 응답 지표 질의 지원.

## 3. 결론

Momento 플랫폼은 보안팀의 컴플라이언스 만족부터 개발자 및 기획자의 분석 생산성 향상까지 조직 전체의 데이터 기반 의사결정을 실현하는 엔터프라이즈 솔루션입니다.
