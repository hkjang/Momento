사내 데이터 유출 없는,
Raw Event 분석 플랫폼

누가, 어느 부서에서, 어느 기능을 사용하는지 원천 소유 및 분석

Momento는 외부 SaaS 서비스로의 데이터 전송 없이 사내 Web 및 App 사용 현황을 원시 이벤트(Raw Event) 수준에서 수집·소유하고 분석하는 자체 호스팅 애널리틱스 엔진입니다. 조직·망 대역 연동부터 Keycloak OIDC, MCP 지표 조회까지 완벽하게 지원합니다.

핵심 기능

이벤트 수집부터 세밀한 행동 분석까지 기업 환경에 맞춤 설계되었습니다

📡

풍부한 JS SDK & 오프라인 큐

PageView, SPA 라우팅, 클릭, 스크롤, 폼 입력, 파일 다운로드, 외부 링크 클릭, JS 에러, Heartbeat를 수집하고 Beacon/오프라인 큐로 전송 손실을 줄입니다.

🔍

원시 이벤트 & 쿼리 빌더

요약 데이터가 아닌 Raw Event를 직접 보존합니다. 커스텀 속성 필터링, 사내 부서/조직별 분류, 2~10단계 퍼널(Funnel) 및 사용자 이동 경로(Path)를 탐색할 수 있습니다.

🌐

사내 망 대역(CIDR) 맵핑

사내 C클래스 및 CIDR IP 대역을 특정 본사, 연구소, 지사 네트워크 이름으로 맵핑하여 사내 물리적 네트워크별 사용 비율을 시각화합니다.

🔐

개인정보 최소 수집 & 보안

관리자가 지정한 민감 Property를 제거하고 URL Parameter를 마스킹합니다. Keycloak OIDC SSO(PKCE), RBAC, API 키 회전 및 감사 로그를 제공합니다.

🤖

Analytics MCP 연동

Streamable HTTP MCP JSON-RPC 표준 엔드포인트를 제공합니다. Claude, Cursor 등의 AI 에이전트가 사내 분석 지표를 직접 대화로 조회할 수 있습니다.

📦

폐쇄망(Air-Gapped) 지원

외부 인터넷 통신이 전면 차단된 폐쇄망 환경을 위한 단일 non-root Docker 이미지와 .tar.gz 오프라인 패키지를 제공합니다.

엔터프라이즈 보안 및 권한

사내 보안 요구사항을 만족하는 다층 보안 체계

🔑

Keycloak OIDC SSO

PKCE(S256)를 적용한 표준 OIDC 인증. Email·이름·부서·조직 Claim을 매핑하며 신규 사용자는 Viewer로 등록됩니다.

🔒

API 키 회전 및 폐기

해시 처리된 API 키를 발급·회전·폐기하며 원문 키는 최초 1회만 표시됩니다. 회전 시 기존 키는 즉시 폐기됩니다.

🛡️

개인정보 필터 정책

차단할 Property key와 URL 정책을 관리하며 PII 값 패턴을 Detect, Warn, Mask 또는 Reject로 처리합니다.

📝

감사 로그 (Audit Trail)

사이트 생성, 키 발급, 개인정보 설정 변경, 사용자 권한 조정 등 주요 관리자 작업을 구조화된 감사 로그로 기록합니다.

개발자 & AI 에이전트 연동

REST API와 Analytics MCP로 자동화 분석 워크플로 구축

JS SDK SDK 코드 예시

단 몇 줄의 코드로 사내 부서 및 커스텀 이벤트를 수집합니다.

javascript — Tracker SDK
// 사용자 식별 (부서 및 조직)
analytics.identify("EMP_2026_091", {
  department: "Platform Engineering",
  organization: "R&D Center"
});

// 기능 사용 이벤트 트래킹
analytics.track("feature_used", {
  service: "intranet_portal",
  feature: "document_exporter",
  button_id: "export_pdf_btn"
});
MCP Analytics MCP JSON-RPC

쉽고 유연한 배포 방식

환경에 맞는 최적의 온프레미스 배포 방식을 선택하세요

🐳 Docker Compose

PostgreSQL과 Momento 단일 컨테이너를 한 번에 구동합니다. 평가 및 사내 검증에 가장 빠른 방식입니다.

cp .env.example .env
# .env 관리자 정보 설정
docker compose up --build

# Web Admin: http://localhost:8080

📦 오프라인 번들 (.tar.gz)

인터넷 통신이 완전히 차단된 사내 폐쇄망 환경을 위한 오프라인 Docker 이미지 아카이브를 제공합니다.

# 릴리스 아카이브 로드
gzip -dc momento-v0.11.0.tar.gz | docker load

# 폐쇄망 컨테이너 실행
docker run -d -p 8080:8080 \
  -e MOMENTO_POSTGRES_DSN='...' \
  momento-v0.11.0

자주 묻는 질문 (FAQ)

Momento는 사내 Web 및 App 서비스의 사용자 행동 데이터(어느 부서가 어떤 기능을 얼마나 사용하는지)를 외부 서비스로 유출하지 않고 Raw Event 수준에서 수집·소유하고 분석하는 온프레미스 이벤트 애널리틱스 플랫폼입니다.

사내 인트라넷, 업무 시스템의 트래픽 데이터에는 임직원의 부서, 조직, 업무 행동 패턴 등 기밀성 정보가 포함됩니다. Momento는 100% 데이터 주권을 유지하며 폐쇄망에서도 안전하게 운영할 수 있습니다.

PostgreSQL 14+ 데이터베이스 하나만 있으면 실행 가능합니다. Redis 등 별도의 인메모리 캐시 서버 없이도 고성능 비동기 수집이 가능하도록 설계되었습니다.

Momento는 /mcp 엔드포인트를 제공하여 Claude Desktop, Cursor 등의 AI agent가 자연어로 "지난 일주일간 가장 많이 사용된 기능 TOP 5는?"과 같이 직접 지표를 질의하고 답변을 받을 수 있습니다.
