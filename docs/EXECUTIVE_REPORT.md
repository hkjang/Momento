## 2. 도입 배경 및 해결하고자 한 핵심 문제 (Problem Statement)

1. **사내 행동 데이터의 외부 유출 보안 위험**:
   - 인트라넷, ERP, R&D 포털 등 사내 주요 업무 시스템 사용 데이터에는 부서 구조, 업무 패턴, 프로젝트 명칭 등 기밀성 정보가 포함됩니다. 기존 외산 SaaS 사용 시 데이터 소유권 분실 및 법적 규제 위반 위험이 상존했습니다.
2. **사내 부서/조직 체계와의 연동 부재**:
   - 일반 범용 분석 도구는 로그인한 사내 임직원의 조직도(부서, 직급)나 접속 네트워크 망(본사, R&D 센터, VPN)을 식별할 수 없어 사내 서비스의 정밀한 도입률 측정이 불가능했습니다.
3. **SaaS 과금 모델로 인한 TCO 부담**:
   - 이벤트 수집량 증가에 따라 기하급수적으로 증가하는 3rd Party SaaS 비용 및 추가 쿼리 비용(BigQuery Export 등)으로 인한 예산 압박.

## 3. 핵심 경쟁력 분석 및 솔루션 비교 (Vendor Comparison)

| 평가 항목 | 외산 3rd Party SaaS (GA4 등) | 타 오픈소스 (PostHog / Mixpanel) | **Momento 엔터프라이즈 솔루션** |
| :--- | :--- | :--- | :--- |
| **데이터 주권 (Sovereignty)** | 외부 클라우드 전송 (위험) | 자체 구축 가능 (구조 복잡) | **100% 온프레미스 완벽 소유** |
| **폐쇄망 (Air-Gapped) 지원** | 지원 불가 | 부분 지원 (외부 패키지 의존) | **완전 지원 (단일 Docker & Tarball)** |
| **인프라 구성 요건** | N/A (SaaS) | Redis, ClickHouse, Kinesis 등 4~5개 | **PostgreSQL 1개 (Redis-Free 단일화)** |
| **사내 계정 (OIDC) 및 RBAC** | 기업용 고가 요금제 필수 | 커스텀 개발 필요 | **Keycloak OIDC (PKCE) 기본 제공** |
| **개인정보 (PII) 자동 마스킹** | 수동 차단 (위반 시 계정 삭제) | 개발자 수동 로직 작성 | **수집기 레벨 자동 정규식 마스킹** |
| **AI 에이전트 연동 (MCP)** | 지원 불가 (REST 래핑 필요) | 지원 안 함 | **Analytics MCP JSON-RPC 표준** |
| **Raw Event 소유권** | BigQuery 추가 과금 필요 | DB 직접 쿼리 | **Raw Event 100% 원천 보존 및 Export** |

## 4. 정량적 / 정성적 도입 기대 효과 (ROI Analysis)

```
========================================================================================
                           [정량적 TCO 절감 및 효과 산출 모델]
========================================================================================
  [1] SaaS 라이선스 비용 절감 : 연간 약 $45,000 ~ $120,000 절감 (이벤트 수집량 비례)
  [2] 인프라 운영 공수 감축   : Redis-Free 단일 컨테이너로 서버 운용비 75% 감소
  [3] 데이터 보안 위험 비용   : PII 자동 마스킹 및 폐쇄망 운영으로 보안 사고 위험 0%
  [4] AI 데이터 분석 효율성   : Analytics MCP 연동으로 리포트 작성 시간 60% 단축
========================================================================================
```

1. **비용 절감 (TCO 75% 감축)**:
   - 외산 유료 애널리틱스 라이선스 수수료를 전면 제거하고, 수집기와 DB를 단일 PostgreSQL 스택으로 경량화하여 서버 자원 및 관리 공수를 획기적으로 낮췄습니다.
2. **사내 데이터 자산화 및 주권 확보**:
   - 원시 이벤트(Raw Event)를 사내 데이터베이스에 직접 저장하므로, 향후 데이터 웨어하우스(DW) 및 사내 AI 모델 학습용 자산으로 무한 활용이 가능합니다.
3. **규정 준수 (Compliance & Security)**:
   - 개인정보보호법 및 ISO 27001 요구사항에 부합하도록 수집기(Collector) 단에서 이메일, 주민번호, 전화번호 패턴을 자동 차단합니다.
