## 2. 핵심 도입 성과 및 벤더 경쟁력 비교 분석

| 비교 항목 | 기존 외산 SaaS (Google Analytics) | 타 오픈소스 분석 도구 | **Momento 플랫폼** |
| :--- | :--- | :--- | :--- |
| **망분리/폐쇄망 지원** | 불가능 (외부 클라우드 필수) | 부분 지원 (인프라 복잡) | **100% 완전 지원 (Air-Gapped 번들)** |
| **인프라 구성 요건** | N/A (SaaS) | ClickHouse/Redis 등 4~5개 | **PostgreSQL 1개 (Redis-Free)** |
| **사내 조직/망 연동** | 지원 안 함 | 수동 Tagging 구현 | **Keycloak OIDC & CIDR 망 맵핑** |
| **개인정보(PII) 차단** | 정책적 차단 (위반 시 계정 정지) | 개발자 직접 구현 | **수집기 레벨 자동 마스킹 엔진** |
| **AI 에이전트 연동** | 제한적 REST API | 별도 파이프라인 구축 | **Analytics MCP JSON-RPC 표준** |
| **Raw Event 소유권** | 추가 비용 (BigQuery Export) | 부분 지원 | **100% Raw Event 원천 소유** |

## 3. 정량적 / 정성적 기대 효과

```
+-----------------------------------------------------------------------+
|                  Momento 도입에 따른 핵심 기대 효과                   |
+-----------------------------------------------------------------------+
|  [1] 인프라 및 외산 SaaS 라이선스 비용 75% 절감                      |
|  [2] 사내 기술 자산 및 데이터 외부 유출 위험 0% (완전 차단)          |
|  [3] AI 에이전트(MCP) 연동을 통한 데이터 분석 공수 60% 단축          |
|  [4] Keycloak OIDC 기반 계정/권한 관리 일원화                        |
+-----------------------------------------------------------------------+
```

1. **비용 절감 (TCO 75% 감축)**: 외산 유료 애널리틱스 라이선스 및 유통 비용을 제거하고, Redis-Free 단일 컨테이너 아키텍처로 인프라 운영 비용을 최적화합니다.
2. **보안성 및 규정 준수 극대화**: 에어갭(Air-Gapped) 환경을 완벽 지원하며, PII 자동 필터 및 Keycloak OIDC(PKCE) 통합으로 보안 사고 위험을 원천 차단합니다.
3. **업무 생산성 향상**: Raw Event 단위 쿼리 빌더 및 Analytics MCP 연동으로 AI 기반 사내 데이터 질의 응답 체계를 구축합니다.

## 4. 향후 추진 전략 및 결론

Momento 온프레미스 이벤트 애널리틱스 플랫폼은 v0.1.0 구축을 통해 엔터프라이즈 환경에 필수적인 핵심 기능(Durable Collector, Raw Event Analytics, PII Masking, Keycloak OIDC, Analytics MCP)을 완벽히 검증했습니다. 본 플랫폼의 전사 확대를 통해 사내 데이터 자산의 보안성과 분석 생산성을 동시에 극대화할 수 있음을 확신하며 본 보고서를 제출합니다.
