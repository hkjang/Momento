Momento 사용자 가이드 (User Guide)

버전: v0.1.0 대상: 개발자, 데이터 분석가, 서비스 기획자 분류: 사용자 매뉴얼

1. 플랫폼 개요

Momento는 사내 웹 및 애플리케이션의 사용자 행동 데이터를 수집하고 분석하는 온프레미스 이벤트 애널리틱스 플랫폼입니다. 사내 데이터가 외부 SaaS로 전송되지 않으며, 사내 부서/조직/CIDR 망 기반으로 원시 이벤트(Raw Event) 수준에서 조회할 수 있습니다.

2. JavaScript SDK 연동 가이드

2.1 스크립트 태그 삽입

웹 서비스 상단 <head> 영역에 비동기 스크립트를 추가합니다.

<script async src="https://momento.example.com/tracker.js" data-site-id="SITE_CORPORATE_001"></script>

2.2 사용자 식별 (identify)

로그인한 사용자의 사내 부서 및 조직 정보를 식별할 때 호출합니다.

analytics.identify("EMP_2026_1042", {
  department: "Digital Platform Team",
  organization: "R&D Center",
  position: "Senior Engineer"
});
보안 주의사항: 주민등록번호, 이메일, 전화번호 등 개인 식별 정보(PII)는 user_id 또는 속성값으로 절대 전달하지 마십시오.

2.3 커스텀 이벤트 트래킹 (track)

analytics.track("document_exported", {
  format: "PDF",
  document_type: "Monthly_Report",
  button_id: "export_btn_top"
});

3. 주요 분석 기능 활용

  • 실시간 (Realtime) & 개요: 현재 접속 중인 활성 사용자 및 이벤트 동향 실시간 모니터링
  • 쿼리 빌더 (Query Builder): 커스텀 속성, 부서 필터, 날짜 범위를 조합한 즉각적 맞춤 탐색
  • 퍼널 분석 (Funnel Analysis): 2~10단계 목표 전환 퍼널 및 단계별 이탈 분석
  • 경로 분석 (Path Analysis): 사용자의 화면 진입부터 최종 목표 달성까지의 이동 노드 시각화

4. 데이터 내보내기 (Export)

분석 결과를 Raw CSV 및 NDJSON 형식으로 원클릭 다운로드하여 사내 BI 도구(Tableau, PowerBI)와 연동할 수 있습니다.
