Momento 시스템 구축 및 도입 종합 보고서

작성일: 2026년 8월 8일 수신: 경영진 및 CTO / CISO 발신: Momento 아키텍처 팀 분류: 경영진 공식 보고서

1. 경영 요약 (Executive Summary)

본 보고서는 사내 핵심 데이터 자산으로 구체화된 Momento 온프레미스 이벤트 애널리틱스 플랫폼의 구축 성과, 보안 아키텍처 완성도, 데이터 주권 확보 방안 및 정량적 기대 효과를 경영진에게 보고하기 위해 작성되었습니다.

Momento 도입 핵심 핵심 가치: 사내 Web 및 App에서 발생하는 임직원의 행동 이벤트 데이터를 외부 SaaS로 유출하지 않고, Raw Event 수준에서 100% 원천 소유하며 사내 부서/조직/CIDR 망 기반으로 입체 분석을 제공합니다.

2. 핵심 도입 성과 및 벤더 경쟁력 비교 분석

비교 항목 기존 외산 SaaS (Google Analytics) 타 오픈소스 분석 도구 Momento 플랫폼
망분리/폐쇄망 지원 불가능 (외부 클라우드 필수) 부분 지원 (인프라 구성 복잡) 100% 완전 지원 (Air-Gapped 번들)
인프라 구성 요건 N/A (SaaS) ClickHouse/Redis 등 4~5개 PostgreSQL 1개 (Redis-Free)
사내 조직/망 연동 지원 안 함 수동 Tagging 구현 Keycloak OIDC & CIDR 망 맵핑
개인정보(PII) 차단 정책적 차단 (위반 시 계정 정지) 개발자 직접 구현 수집기 레벨 자동 마스킹 엔진
AI 에이전트 연동 제한적 REST API 별도 파이프라인 구축 Analytics MCP JSON-RPC 표준
Raw Event 소유권 추가 비용 (BigQuery Export) 부분 지원 100% Raw Event 원천 소유

3. 정량적 / 정성적 기대 효과

  • 비용 절감 (TCO 75% 감축): 외산 유료 애널리틱스 라이선스 및 유통 비용을 제거하고, Redis-Free 단일 컨테이너 아키텍처로 인프라 운영 비용을 최적화합니다.
  • 보안성 및 규정 준수 극대화: 에어갭(Air-Gapped) 환경을 완벽 지원하며, PII 자동 필터 및 Keycloak OIDC(PKCE) 통합으로 보안 사고 위험을 원천 차단합니다.
  • 업무 생산성 향상: Raw Event 단위 쿼리 빌더 및 Analytics MCP 연동으로 AI 기반 사내 데이터 질의 응답 체계를 구축합니다.

4. 향후 추진 전략 및 결론

Momento 온프레미스 이벤트 애널리틱스 플랫폼은 v0.1.0 구축을 통해 엔터프라이즈 환경에 필수적인 핵심 기능을 완벽히 검증했습니다. 본 플랫폼의 전사 확대를 통해 사내 데이터 자산의 보안성과 분석 생산성을 동시에 극대화할 수 있음을 확신하며 본 보고서를 제출합니다.
